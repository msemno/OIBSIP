A temporary local Python HTTP service was started on 127.0.0.1:8080 to provide a safe local service for Nmap detection.

## Scan 1 — Basic Nmap Scan

Command:
nmap 127.0.0.1

Summary:
The basic scan found one open TCP port.

Result:
8080/tcp open http-proxy

Interpretation:
Nmap's basic scan identified port 8080 as open. In a basic scan, Nmap may identify the service based on common port mappings rather than full service probing. Because of that, the service name appeared as http-proxy.

## Scan 2 — Service and Version Detection

Command:
nmap -sV 127.0.0.1

Summary:
The service/version scan confirmed that port 8080 was running an HTTP service.

Result:
8080/tcp open http SimpleHTTPServer 0.6 (Python 3.14.7)

Interpretation:
The -sV scan actively probed the open port and identified the service as a Python SimpleHTTPServer. This is more accurate than the basic scan because service detection uses probing instead of only relying on port number assumptions.

## Scan 3 — OS Detection

Command:
sudo nmap -O 127.0.0.1

Summary:
OS detection was attempted, but Nmap did not return an exact OS match.

Result:
No exact OS matches for host.

Interpretation:
This is acceptable because OS detection is not always exact, especially when scanning localhost or when Nmap does not have enough network behavior to make a confident match.

## Open Port Analysis

| Port | State | Service | Detected Version | What It Does | Security Observation |
|---|---|---|---|---|---|
| 8080/tcp | Open | HTTP | SimpleHTTPServer 0.6 / Python 3.14.7 | Serves web content over HTTP from the local test directory. | In this lab it is safe because it is bound to 127.0.0.1. In a real environment, exposed HTTP services should be reviewed, patched, monitored, and protected with access control and HTTPS where sensitive data is involved. |
