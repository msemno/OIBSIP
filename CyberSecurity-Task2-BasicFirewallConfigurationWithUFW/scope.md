# Scope — Task 2 Basic Firewall Configuration with UFW

## Assessment Name
Oasis Infobyte Task 2 — Basic Firewall Configuration with UFW

## Assessor
Mahmoud Khaled

## Environment
Local Kali Linux VM

## Purpose
Configure and test basic host firewall rules using UFW.

## In Scope
- Local Kali VM firewall configuration
- UFW inbound traffic rules
- SSH allow rule
- HTTP deny rule
- Additional HTTPS allow rule
- Additional Telnet deny rule
- Firewall status verification
- Local blocked-traffic test

## Out of Scope
- Public systems
- Company systems
- Third-party systems
- Destructive firewall testing
- Production firewall changes

## Safety Note
SSH is allowed before enabling UFW to reduce lockout risk.
